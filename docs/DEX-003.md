## Asset contract

- Target 16x16 overworld actor frames, four cardinal facings, with horizontal flip for mirrored right pose as engine permits.
- Existing verified sprite format: 12 tiles / 192 bytes of indexed 2bpp data, distributed in the 16x48 source sheet matching Bulbasaur and Ivysaur.
- Keep large Venusaur silhouette legible at Game Boy resolution: squat quadruped, large distinctive flower and foliage, broad shoulders and unmistakable outline. Confirm flower/leaf readability, avoid removing canonical defining features merely to fit.
- Create and version a concept preview and pixel asset separately. Obtain explicit visual approval before production merge. Track raw source PNG, 2bpp export, checksum, preview, and emulator screenshots.

## Game Boy Color compatibility requirement

Pokémon Yellow is a Game Boy-compatible game with distinct color behavior on Game Boy Color hardware. Preserve the genuine 2bpp indexed pixel values and test their appearance under both original DMG grayscale and actual GBC compatibility palettes. Four grayscale shades in a source sheet must not be mistaken for four arbitrary per-Pokémon colors; verify the real palette assignment in the Yellow/GBC rendering path before promising species-specific colors. Include a color preview labeled as a *GBC compatibility simulation* only when backed by palette data, and capture actual GBC-mode emulator evidence separately. Do not sacrifice DMG sprite legibility for color. SGB behavior is independently verified.
