## Isolated ROM prototype

- New `SPRITE_IVYSAUR` at `$53`, appended after the unchanged vanilla sprite IDs to avoid shifting them.
- Registered 12-tile graphics pointer and full 192-byte archive-derived `gfx/sprites/ivysaur.2bpp` source.
- `CheckForFourTileSprite` specifically recognizes this appended ID as a regular walking sprite rather than incorrectly treating it as a four-tile still sprite.
- In DEBUG builds only, the Red's House 1F lab station temporarily displays Ivysaur. Release builds preserve the Mom NPC.
- Species-specific verifier copied from established YEL-TEST-003, with the expected ID and image bytes updated for DEX-002; GitHub Actions builds release and DEBUG variants and runs the new test.
